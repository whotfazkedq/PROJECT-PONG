# PROJECT-PONG
A small pong project made with GameMaker trying to recreate the classic pong game

This is my first game project, created mainly as a way to learn the basics of game development, programming, and GameMaker itself
The project started as a simple recreation of the classic Pong: two paddles, a ball, a score system, and a basic game loop. As I continue working on it, I'm experimenting with menus, settings, different game states, and other small features
More features may be added as the project develops

This project is an experiment to learn the basics of game developement
